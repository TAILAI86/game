### 玩法

点击金币赚钱 → 雇员工自动产出 → **扩张产业做倍率** → 攒够身家重生换永久加成 → 用天赋点把收益推到下一个量级 → 拿闲钱炒股坐享分红。

💡 挑战模式从零开始：金币、升级与股票持仓都会暂时清空，先点几下金币攒出本金，就能重新开市投资。

**核心循环**：*手动点击起步* → *买升级把点击变成被动收入* → *被动收入推高总财富、解锁里程碑与成就（永久加成）* → *财富到 100 万触发重生，把进度换成声望与贤者水晶* → *用天赋点横向拉开差距* → *用闲钱进股市博取差价与分红* → *面对更高目标继续循环*。每轮循环都会永久抬高下一轮的起点倍率。

### 产业线：为什么它是这个版本最重要的改动

在 v1.9.0 之前，全部升级里**只有「加值型」**（每秒 +2 元、每次点击 +1 元）。加值型升级的收益随等级**线性**增长，于是财富曲线也近似线性 —— 实测下来：

| 里程碑 | 旧曲线到达所需时长 |
|---|---|
| 亿级大佬 ¥1e8 | 约 17 小时 |
| 十亿传说 ¥1e10 | 约 32 天 |
| 百亿神话 ¥1e12 | 约 4 年 |
| 千亿帝国 ¥1e15 | 约 1,182 年 |

也就是说，**12 档里程碑里有 8 档、35 个成就里有 2 个、6 个挑战的目标全部是"永远看不到的内容"** —— 玩家玩一年也只能走到「亿级大佬」。

v1.9.0 的解法是引入**倍率型升级（产业线）**，让收益本身能被乘算，曲线得以指数化。同时把声望收益率提到 +10%/点、声望基数从 √(累计财富/1e6) 放宽到 √(累计财富/1e5)，让「重生」从一笔亏本买卖变成正反馈。调整后的实测曲线：

| 时间（活跃游玩） | 累计财富 | 声望 | 产业倍率 | 被动/手动产出比 |
|---|---|---|---|---|
| 30 分钟 | ¥194 万 | 3 | ×1.24 | 82% |
| 1 小时 | ¥917 万 | 9 | ×1.24 | 136% |
| 2 小时 | ¥5,357 万 | 21 | ×1.60 | 388% |
| 4 小时 | ¥4.95 亿 | 69 | ×2.02 | 916% |
| 8 小时 | ¥90 亿 | 297 | ×3.70 | 2338% |

**财富曲线从"每小时等比慢爬"变成"每 0.4~0.7 小时翻一番"**，12 档里程碑与 37 个成就第一次全部落在可玩区间内。

### 挑战目标也一起校准了

挑战里金币与升级全部清零、从零重建，所以目标值必须跟「玩家在该阶段的真实收入能力」匹配。旧目标（1e12~1e18）实测完成度：

| 挑战 | 旧目标 | 中期玩家 1 小时实测可达 | 旧完成度 | 新目标 | 新完成度 |
|---|---|---|---|---|---|
| 纯净试炼（里程碑失效） | 1e15 | 6.7e10 | 0.007% | **5e10** | 134% |
| 手动时代（禁自动化） | 1e12 | 1.03e11 | 10.3% | **1e11** | 103% |
| 平凡之始（倍率×0.1） | 1e18 | 2.1e9 | 0.002% | **5e9** | 42% |
| 无暴击 | 1e14 | 6.7e10 | 0.067% | **1e11** | 67% |
| 断网经营（禁离线） | 1e16 | 6.7e10 | 0.0067% | **1e11** | 67% |
| 无股之徒（禁投资） | 1e17 | 6.7e10 | 0.0067% | **1.5e11** | 45% |

新目标让每个挑战都需要认真打 30 分钟到 2 小时，而不是望洋兴叹。

### 天赋树

天赋是 v1.0.0 的重头戏 —— 声望不再只是一个数字，而是能换来**实打实的永久成长**。

| 分支 | 天赋 | 效果 |
|---|---|---|
| 💰 财富 | 生财有道 | 全局收益 +4%/级（10 级） |
| 💰 财富 | 点石成金 | 点击收益 +12%/级（8 级） |
| 💰 财富 | 复利机器 | 离线收益 +20%/级（8 级） |
| ⚙️ 效率 | 批量议价 | 升级价格 -3%/级（8 级，最高 -24%） |
| ⚙️ 效率 | 幸运加成 | 暴击率 +3%/级（8 级） |
| ⚙️ 效率 | 通货膨胀 | 升级涨价幅度 -2%/级（8 级，最高 -16%） |
| 🍀 稳健 | 长线待机 | 离线结算上限 +2 小时/级（6 级） |
| 🍀 稳健 | 勤能补拙 | 每日任务奖励 +25%/级（6 级） |
| 🍀 稳健 | 细水长流 | 重生保留累计财富的 5%/级 作为启动资金（5 级） |
| 🍀 稳健 | 及时行乐 | 每次签到额外获得天赋点（5 级） |

**天赋点从哪来？** 重生回馈（每点声望约 0.5 点）、每日任务全清（+1 点）、签到（天赋「及时行乐」）。

### 项目结构

《金币工厂》是**单文件**网页游戏，所有 HTML / CSS / JS 全部内联在一个文件里，没有构建步骤：

| 文件 | 说明 |
|---|---|
| `挂机小游戏/金币工厂.html` | 唯一源码与成品；双击即玩，无需任何依赖 |
| `挂机小游戏/_dev/smoke.js` | 无头端到端回归测试（jsdom 驱动，含虚拟时钟） |
| `挂机小游戏/_dev/sim.js` | 经济模拟器（模拟理性玩家的完整核心循环） |
| `挂机小游戏/_dev/sim_challenge.js` | 挑战可达性测量（校准挑战目标用） |
| `挂机小游戏/_dev/browser_check.js` | 真实浏览器控制台错误检查（Edge 无头驱动主流程） |
| `挂机小游戏/_dev/responsive.js` | 多档视口响应式体检（横向溢出 / 元素越界） |
| `挂机小游戏/_dev/make_shots.js` | 生成各页签截图变体（人工走查用） |
| `挂机小游戏/_dev/push_via_api.py` | 走 GitHub API 推送并创建 PR（本机代理挡了 git 主机时的唯一通路） |

代码（内联 `<script>`）按职责大致分为：

- **状态与存档**：`defaultState()` 定义全部进度字段；`load()/save()` 负责读写；`mergeState()` 处理多标签页增量合并（**持仓 / 天赋 / 收入来源 / 任务进度全部纳入合并，杜绝静默丢档**）
- **经济核心**：`incomePerSec()` 每秒收益、`globalMult()` 全局倍率、`cost(u)` 升级价格曲线、`multBonus()` 产业倍率、`marketDividend()` 股票分红
- **行情系统**：`ensureMarket()/marketPrice()/marketBuy()/marketSell()/renderMarket()` 负责行情主流程；v1.6.0 起拆分为 `marketPriceTick()`（价格波动）与 `marketPayDividend(dt)`（**按真实经过时间派息**，保证"界面显示的每秒分红"就是实际到账）；另有 `drawSpark()`（走势图）、`marketBuyBulk()` / `marketBuyMax()`（批量 / 买满）、`marketSmartPick()` / `marketSmartBuy()`（智能投资）、`marketSellAll()`（一键清仓）、`marketBuyPrice()` / `marketSellPrice()`（买卖价差口径）
- **成长系统**：重生 `doPrestige()`、天赋 `perkMult()`、里程碑 `checkMilestones()`、成就 `checkAch()`、挑战 `enterChallenge()/exitChallenge()`、挑战限制可见化 `upgradeBlocked()`
- **界面渲染**：`refresh()` 与各 `renderXxx()` 按页签增量刷新；`switchTab()` 切换页签；行情大厅采用**引用缓存 + 局部更新**（`mktUI.cards`），避免整块重绘导致按钮闪烁与点击丢失
- **主循环**：底部 `setInterval` 每秒推进收益、事件、存档与各类检查

### 开发与验证

改完数值或逻辑后，在 `挂机小游戏/` 目录下：

```bash
npm install                 # 只需要 jsdom 一个开发依赖
npm run verify              # 回归 + 真实浏览器控制台检查 + 响应式体检（三件套）

node _dev/smoke.js          # 无头端到端回归：36 项断言，含存档往返与脏存档容错
node _dev/browser_check.js  # 真实 Edge 无头跑主流程，捕获 console.error / window.onerror
node _dev/sim.js 7200       # 经济模拟：跑 2 小时核心循环，检查被动收入是否压过手动点击
node _dev/sim_challenge.js  # 挑战可达性：校准 6 个挑战的目标值
node _dev/responsive.js     # 响应式体检：320~1440px 共 9 档，检查横向溢出与元素越界
```

`sim.js` 与 `sim_challenge.js` 会直接读取游戏里真实的 `cost()` / `paybackOf()` / `globalMult()`，
所以改数值后不用改模拟脚本，结论自动跟着变。
